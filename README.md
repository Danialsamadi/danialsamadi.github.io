# Danial Samadi - Developer Portfolio

🚀 **Live Site**: [danialsamadi.github.io](https://danialsamadi.github.io) | [0xdanis.com](https://0xdanis.com)

A modern, performance-focused developer portfolio showcasing full-stack projects, systems programming expertise, and open-source contributions. Built with Astro for blazingly fast load times.

## 🎯 Highlights

This portfolio features 10+ production-ready projects demonstrating:
- **Performance Optimization**: 99.7% improvement in Go-based config processing
- **Full-Stack Development**: PWAs with offline-first architecture and cloud sync
- **Systems Programming**: Memory management tools and profiling utilities
- **Clean Architecture**: Design patterns and enterprise-grade applications

## ✨ Featured Projects

### v2go - High-Performance Config Aggregator
Go-based processor handling 20,000+ configurations in 11 seconds with concurrent processing and auto-deduplication. **65+ GitHub stars**.

### Syncodoro - Production PWA
Full-featured Pomodoro timer with offline-first architecture, Supabase cloud sync, session analytics, and export capabilities.

### Free-macOS - Terminal Memory Monitor
Production CLI tool replicating Linux's `free` command for macOS with Rich terminal UI and Poetry package management.

## 🛠️ Technologies

**Languages**: Go, Python, TypeScript, JavaScript, Java, PHP  
**Frontend**: React, Astro, Tailwind CSS, Three.js, PWA  
**Backend**: Node.js, Django, Supabase, PostgreSQL, MySQL  
**DevOps**: Docker, CI/CD, Git, Linux, macOS  

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
